Hogwarts Management System

A terminal-based student management application built with Python.

This project allows users to register Hogwarts students, view student records, and search for students by name.

## 🚀 Features

- **Register Students:** Add new students with their names and Hogwarts houses.
- **View Students:** Display all registered students.
- **Search Students:** Find students by their names.
- **Interactive Menu:** Navigate through the application using a simple terminal menu.

- Functions and return values
- Lists and list methods (`append()`)
- Loops and conditional statements
- Classes and objects
- Constructors (`__init__`)
- String representation (`__str__`)
- Object attributes
